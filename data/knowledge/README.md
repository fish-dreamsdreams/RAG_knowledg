# 场景文档（演示数据集）

按 PRD §3.1「演示数据」造的双场景文档。导入后由 tasklist 15.1 配置 ACL。

## 场景 A：财务薪酬隔离

| 文件 | 格式 | 建议 ACL | 演示用途 |
|------|------|----------|----------|
| `scenario-a/薪酬管理制度.md` | MD | 部门=财务部 | sales01 提问被拒且不泄标题正文；finance01 可正常溯源 |
| `scenario-a/财务报销制度.pdf` | PDF | 部门=财务部 | 审批权限分级问答；**覆盖 PDF 解析（MinerU）分支** |
| `scenario-a/差旅费用标准.md` | MD | 全局公开 | 所有账号可读，用于对照「有权溯源卡片」 |

关键事实点（答案可被引用核验）：住宿限额一线 600 / 二线 450 / 其他 350 元每晚；伙食补助一线 120 / 其他 100 元每天；
报销时限 30 个自然日；审批分级 2000 / 10000 / 50000 元；月薪次月 10 日发放；调薪窗口每年 4 月。

## 场景 B：客服 FAQ 与知识缺口

| 文件 | 格式 | 建议 ACL | 演示用途 |
|------|------|----------|----------|
| `scenario-b/客服退款流程.md` | MD | 部门=客服部 | 生鲜 24 小时 / 7 天无理由等高频问答 |
| `scenario-b/清关问题说明.txt` | TXT | 部门=客服部 | 清关时效问答；与缺口问法呼应 |

关键事实点：生鲜 24 小时内、普通商品 7 天无理由；退款审核 48 小时、到账 3-7 个工作日；
保税仓清关 1-3 个工作日、直邮 3-7 个工作日（大促可延至 10 个）；超时补偿 20 元券或取消订单全额退款。

## 格式覆盖

- **MD**：薪酬管理制度、差旅费用标准、客服退款流程（直读，不经外部服务）。
- **TXT**：清关问题说明（直读）。
- **PDF**：财务报销制度，由 `scripts/make_demo_pdf.py` 从 Markdown 渲染，用于验证 MinerU 在线解析链路。
  该文件需要 `MINERU_API_KEY` 才能导入；未配置时场景 A 的主路径仍可由两个 MD 文档支撑。
- **DOCX**：尚无样例。需要时把 DOCX 原件放进 `scenario-a/` 即可，无需改代码。

重新生成 PDF：

```bat
uv run --with reportlab python scripts\make_demo_pdf.py
```

```bat
cd backend
.venv\Scripts\python.exe -m app.services.demo_logs
```
